# @rocketc/cli

RocketC 命令行工具。

The RocketC command-line tool.

## 安装 / Installation

```bash
npm install -g @rocketc/cli
# 或 / Or
pnpm add -g @rocketc/cli
```

## 使用 / Usage

```bash
rocketc
```

## 开发 / Development

```bash
# 安装依赖 / Install dependencies
bun install

# 开发模式 / Development mode
bun run dev

# 构建 / Build
bun run build
```
